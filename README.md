## 🚀 Projects

### Project 1: Connect Angels
Connect Angels is a web application focused on bringing people together through **events** and **chat**. Users can discover and take part in events and talk to each other in one place, so the platform works as both a networking space and a community hub.

**What it offers:**
- 📅 Event features to create, explore, and participate in events
- 💬 Chat features for direct communication between users
- 🎨 A clean, responsive interface that works on desktop and mobile
- ☁️ Deployed on Vercel for fast, reliable access

 **Github Link:** [Connect Angels](https://github.com/connectangels25/Connectangel)
 **Live Link:** [Connect Angels](https://connectangels-alpha.vercel.app/)

### Project 2: Incubation Platform (Arba360)
The Incubation Platform, branded **Arba360**, is a Pre-Incubator and Incubator platform built to help founders launch and grow their startups. It supports early-stage ideas through mentorship, funding support, and program management, so a startup can move from idea to execution in one place.

**What it offers:**
- 🌱 Pre-incubator and incubator programs for startups at different stages
- 🤝 Mentorship and guidance for founders
- 💰 Funding and growth support
- 🔐 Secure login with an authenticated dashboard
- 📊 A dashboard to track progress and manage activity
- 
   **Guthub Link:** [Incubation Platform](https://github.com/connectangels2026/IncubatorPlatform)
   **Live Link:** [Incubation Platform](https://incubationplatform.netlify.app/)
